# Viranda Store Annual Report 2026 

## Project Overview
The **Viranda Store Annual Report 2026** is an Excel-based data analysis project designed to analyze store sales performance, understand customer purchasing behavior, and identify key business trends using data visualization and reporting techniques.

The project uses Microsoft Excel to transform raw sales data into meaningful insights that can help businesses make better, data-driven decisions.

##  Objectives
- Analyze overall sales and order performance.
- Identify top-performing product categories and sales channels.
- Understand customer purchasing patterns.
- Compare sales performance across different regions.
- Create interactive dashboards for easy data interpretation.
- Generate actionable business insights from sales data.

##  Tools & Technologies
- **Microsoft Excel**
- Data Cleaning and Preparation
- Excel Formulas and Functions
- Pivot Tables
- Pivot Charts
- Slicers and Filters
- Data Visualization
- Interactive Dashboard Creation

##  Key Analysis Areas
- **Sales Analysis:** Evaluate overall sales and order trends.
- **Category Analysis:** Identify product categories contributing to sales.
- **Customer Analysis:** Understand customer behavior and purchasing patterns.
- **Regional Analysis:** Compare performance across different locations.
- **Sales Channel Analysis:** Examine performance across available sales channels.
- **Dashboard Reporting:** Present key performance indicators (KPIs) and insights visually.

##  Project Workflow
1. Import and understand the raw dataset.
2. Clean the data by checking duplicates, missing values, and inconsistencies.
3. Organize the data for analysis.
4. Use Excel formulas and Pivot Tables to summarize information.
5. Create charts and visualizations to identify trends.
6. Build an interactive dashboard using charts, filters, and slicers.
7. Summarize findings and business recommendations.

##  Business Value
This project demonstrates how Excel can be used to convert sales data into actionable insights, monitor business performance, identify trends, and support data-driven decision-making.
